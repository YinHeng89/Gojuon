# かなの庭 · 五十音学习

![かなの庭 首页预览](preview.png)

> 从一声「あ」开始。听、读、写、练，在自己的节奏里认识日语的第一扇门。

一个纯静态、无需后端的五十音学习网站。没有构建步骤，没有第三方依赖，没有账号系统 —— 打开 `index.html` 就能用，断网也能用。

---

## 快速开始

最简单的方式是**直接双击 `index.html`**。

不过更推荐用一个本地静态服务器，避免浏览器 `file://` 协议对 `localStorage` 和音频加载的限制：

```bash
python3 -m http.server 4173
```

然后访问 <http://127.0.0.1:4173>。

任何静态托管都能直接部署（GitHub Pages、Vercel、Nginx、对象存储……），把整个目录原样上传即可。

## 功能

### 五十音图

平假名 / 片假名一键切换，按清音、浊音、半浊音、拗音分类浏览。点击任意假名弹出详情：读音、罗马音、发音提示、中日文例词与发音。支持一键标记为已掌握，并可直接跳转到书写练习。

### 听读小测

两种玩法：

- **看字选音** —— 给出假名，选出正确的罗马音
- **听音选字** —— 播放发音，选出对应的假名

可选范围：清音 / 浊音·半浊 / 拗音 / 全部，一轮 10 题。没有倒计时，答错不惩罚。答对的假名自动收入「已掌握」，答错的进入错题本。

> 出题时会避开同音假名。日语里「じ / ぢ」同读 *ji*、「ず / づ」同读 *zu*、「お / を」同读 *o*，这类组合不会同时出现在一道题里，以免出现两个正确答案。

### 书写练习

在田字格中临摹全部 104 个音节，支持鼠标、触控与手写笔。提供撤销单笔、清空、隐藏字帖，以及导出 1200×1200 的字帖 PNG。笔画以归一化坐标存储，窗口缩放后能正确重绘。

### 学习足迹

- 平假名 / 片假名掌握度环形图
- 清音 / 浊音·半浊 / 拗音的分类进度条
- 连续学习天数、最佳连击、累计作答
- 最近 28 天的活动热力图
- 错题回顾（答对后自动移出）

### 每日三件小事

听一个假名、写一个字、完成一轮小测。每天刷新，只是轻轻推你一把。

## 数据与发音

音节数据集中在 `assets/data.js`，每个条目形如：

```js
make('shi', 'し', 'シ', 'shi', 'seion', 'sa', 1,
  ex('しお', '塩', '盐'), ex('シャツ', '', '衬衫'),
  { note: '读 shi，不读 si。嘴唇放松，像轻轻送出一口气。' })
//  id    平假名 片假名 罗马音  分类    行   列   平假名例词      片假名例词      可选：发音提示 / 异读
```

`extra` 里可选两个字段：

- `note` —— 显示在详情弹窗里的发音提示
- `altR` —— 异读。例如「を」的 `r` 是 `wo`、`altR` 是 `o`

发音音频使用 macOS 日语语音合成预生成，页面同时保留浏览器 `SpeechSynthesis` 作为例词朗读与加载失败时的回退。**新增音节时记得同步添加 `audio/<id>.m4a`。**

## 隐私

所有学习进度保存在浏览器的 `localStorage` 里，**不上传任何数据，也不需要账号**。

| 键名 | 内容 |
| --- | --- |
| `kanaGarden.v1` | 掌握情况、错题、统计、主题外的全部进度 |
| `kanaGarden.theme` | 主题偏好（`light` / `dark`） |

超过 180 天的活动记录会在加载时自动清理。想从头开始，可以在「学习足迹 → 重置全部学习进度」里清空（需要二次确认）。

## 开发提示

这个项目没有构建步骤，改完刷新即可。几个值得知道的点：

- **主题**：`<html data-theme>` 决定配色。首屏有一段内联脚本提前读取偏好，避免刷新时的白闪。
- **弹窗圆角**：外层 `.kana-dialog` 与内层 `.dialog-shell` 共用 `--dialog-radius`（定义在 `styles.css` 的 `:root`）。内层若小于外层，拐角会被外层的裁剪区域吃掉。
- **总数全部由数据推导**：46 / 20 / 5 / 33、104、208、92 / 50 / 66 这些数字都来自 `countInGroup()` 与 `DATA.items`，页面上的 HTML 只是占位值，由 `syncDerivedCounts()` 在启动时写入。**增删音节只需改 `assets/data.js`**（记得同时补 `audio/<id>.m4a`），不用去别处找数字。
- **字体**：不引入 webfont，全部使用系统字体栈。日文假名走 `--font-jp`，且**日文字族必须排在中文前面** —— 中文优先时假名会被渲染成中文字形变体（「ソ/ン/シ/ツ」的笔画角度、「あ/い」的起收笔都与日文字形不同）。
- **`lang="ja"` 不可省**：页面主语言是 `zh-CN`，所有日文体文本都单独标了 `lang="ja"`。这不只是无障碍要求 —— iOS / macOS 会依据 `lang` 选择 CJK 回退字体，标错会直接导致假名用中文字形渲染；屏幕阅读器也会拿中文音去读假名。新增日文文本时请一并加上。
- **无障碍**：已支持 `prefers-reduced-motion`、跳转链接、`aria-live` 播报与键盘操作。

## 说明

发音音频为语音合成生成，仅用于入门跟读，与真人发音存在差距。五十音之外的内容（长音、促音、声调、汉字音读训读等）不在本项目的覆盖范围内。

Made for slow learners. 慢慢来，也算数。
